# الرابع العلمي — نسخة مرتبة للنشر

المشروع يضم موقع المكتبة وواجهة API وبوت تيليجرام ضمن خدمة واحدة، ويستخدم قاعدة بيانات واحدة. لا يحتوي على ملفات تعليمية وهمية؛ أضف الملفات الحقيقية من البوت أو لوحة الإدارة.

## هيكل المشروع

- `app/main.py`: الموقع وواجهة API.
- `app/bot.py`: البوت ولوحة المالك.
- `app/database.py`: قاعدة البيانات والمواد الافتراضية.
- `web/`: ملفات الموقع ولوحة إدارة الموقع.
- `requirements.txt`: المكتبات.

## إعداد الاستضافة

اجعل Build command:

```bash
pip install -r requirements.txt
```

واجعل Start command:

```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

ثم أضف متغيرات البيئة التالية في صفحة Environment Variables لدى الاستضافة:

- `BOT_TOKEN`: توكن البوت من BotFather.
- `ADMIN_API_KEY`: مفتاح سري طويل تختاره أنت للوحة إدارة الموقع.
- `DATABASE_URL`: رابط PostgreSQL من مزود قاعدة البيانات.
- `SITE_URL`: رابط الموقع النهائي الذي يبدأ بـ `https://`.
- `BOT_USERNAME`: اسم البوت من دون `@`، حاليًا `YIFiabot`.
- `OWNER_ID`: `7683201905`.
- `MANDATORY_CHANNEL`: `@Kii_8i`.

**لا تضع التوكن داخل `main.py` أو `bot.py` أو ملفات HTML/JavaScript، ولا ترفعه إلى GitHub.** لا تكتب علامات اقتباس حول القيم في شاشة متغيرات البيئة إلا إذا كانت الاستضافة تطلب ذلك صراحةً.

## تنبيه مهم لقاعدة البيانات

لا تستخدم SQLite محلية إذا كان المطلوب أن تبقى البيانات محفوظة بعد إعادة تشغيل الخدمة. أنشئ PostgreSQL وضع رابطها في `DATABASE_URL`. إذا كان البوت القديم يعمل في خدمة أخرى، فلا تشغّل البوت الجديد بالتوكن نفسه في الخدمتين معًا. بعد التأكد من أن النسخة الجديدة تعمل، أوقف polling في الخدمة القديمة أو اجعل الخدمة القديمة تستخدم قاعدة البيانات نفسها وفق تصميم منفصل.

## لوحة إدارة الموقع

بعد النشر افتح `https://رابط-موقعك/admin.html` وأدخل القيمة نفسها الموجودة في `ADMIN_API_KEY`. لا تشارك المفتاح مع أحد.

## اختبار محلي

```bash
pip install -r requirements.txt
pytest -q
```

تُشغّل واجهة الموقع حتى لو لم يُضف `BOT_TOKEN`، لكن إرسال الملفات ومعاينة تيليجرام لا يعملان دون توكن صالح.
